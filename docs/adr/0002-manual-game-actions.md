# ADR 0002: Manual game-changing actions

- Status: accepted
- Date: 2026-08-01

## Decision

The extension may observe and recommend, but the user performs every game-changing action in the EA Web App.

## Consequences

No automation code may invoke purchase, bid, list, SBC submit, pack open, discard, quick-sell, or recovery actions. Recommendation output must remain explainable and dismissible.
