# Data sources and provenance

Use the highest available source in this order:

1. User-confirmed facts.
2. Normalized state visibly rendered by the EA Web App.
3. User-entered PlayStation market observations.
4. Public FUT.GG pages opened by the user.
5. A future documented, explicitly authorized API.

Every observation records its source, collection time, and confidence. Market values also record platform and freshness. Recommendations must distinguish known facts from assumptions.

FUT.GG integration begins with deterministic deep links and user-entered observations. The system must continue working if FUT.GG is unavailable.
